# Personal Website

This repository contains the source code for my personal website, which serves as a portfolio to showcase my projects and provide information about myself.

## Project Structure

- **index.html**: The main entry point of the website, featuring links to other pages.
- **about.html**: A page detailing my background, skills, and interests.
- **projects.html**: A showcase of my projects, linking to detailed markdown files.
- **contact.html**: Contains my contact information and a contact form.
- **resume.html**: Presents my resume, summarizing my professional experience and skills.
- **assets/**: Contains all the static assets for the website.
  - **css/**: Contains stylesheets for the website.
    - **styles.css**: The main stylesheet defining the layout and appearance.
  - **js/**: Contains JavaScript files for interactivity.
    - **main.js**: The main JavaScript file for handling dynamic content.
  - **data/**: Contains structured data files.
    - **projects.json**: JSON file with data about my projects.
- **projects/**: Contains markdown files for each project.
  - **project-1.md**: Detailed information about project 1.
  - **project-2.md**: Detailed information about project 2.
- **CNAME**: Configuration file for custom domain settings.
- **.gitignore**: Specifies files to be ignored by Git.
- **LICENSE**: Licensing information for the website.
- **README.md**: Documentation for the project.

## Getting Started

To set up the website locally, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/personal-website.git
   ```

2. Navigate to the project directory:
   ```
   cd personal-website
   ```

3. Open `index.html` in your web browser to view the website.
